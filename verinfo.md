# System Information

## Version Details
- **Application**: Inventory Manager
- **Version**: 1.0.3
- **Release Date**: October 2024
- **Status**: Beta

## Features
- Inventory management with locations and racks
- Item categorization and tagging
- Visual storage rack management
- Backup and restore functionality
- Magic parameters for item attributes
- Item Description with Markdown support
- Import/Export capabilities for database and configurations
- Role-based access control (RBAC)
- Now with card view for item
- Item page now on dedicated page
- Search and locate item at Visual Storage
- Now system can run fully offline 
- (only first startup need online for library download)

- Advanced item search, including Magic Parameter filters with AND / OR
- Kanban boards with card move / duplicate between boards
- Two-factor authentication (TOTP) and rate-limited login
- Automatic database upgrades (a backup copy is taken first)
